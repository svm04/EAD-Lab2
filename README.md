# Library API

A RESTful API for a **Library Management System**, built for **IN3101 Enterprise Application Development** (Lab Sheet 02) at the Faculty of Information Technology, University of Moratuwa.

It supports full CRUD for books, stores data in MySQL through Spring Data JPA, validates input, and documents every endpoint with Swagger UI.

## Tech stack

| Layer | Technology |
|---|---|
| Language | Java 21 |
| Framework | Spring Boot 4.1.1 (Spring Web MVC) |
| Persistence | Spring Data JPA, Hibernate 7 |
| Database | MySQL 9 |
| Validation | Jakarta Bean Validation (Hibernate Validator) |
| API docs | springdoc-openapi 3.1.1 (Swagger UI) |
| Build | Maven (wrapper included) |

## Architecture

```
Client (Postman / Swagger UI)
        │  HTTP + JSON
        ▼
BookController   @RestController   maps URLs to methods
        ▼
BookService      @Service          business logic
        ▼
BookRepository   JpaRepository     data access (no SQL)
        ▼
MySQL            library_db.book   table created by Hibernate
```

```
src/main/java/lk/ac/mrt/fit/library_api/

├── model/Book.java
├── repository/BookRepository.java
├── service/BookService.java

```

## Getting started

### Prerequisites

- JDK 21
- MySQL 8.4 or newer, running on `localhost:3306`

### 1. Create the database

```sql
CREATE DATABASE library_db;
```

### 2. Configure your credentials

Database credentials are kept out of git. Copy the example file and fill in your own values:

```bash
cp .env.example .env
```

```properties
DB_URL=jdbc:mysql://localhost:3306/library_db
DB_USERNAME=root
DB_PASSWORD=your_root_password
```

`application.properties` loads `.env` automatically, and `.env` is listed in `.gitignore`.

### 3. Run the application

```bash
./mvnw spring-boot:run        # macOS / Linux
.\mvnw.cmd spring-boot:run    # Windows
```

The API starts on **http://localhost:8080**. Hibernate creates the `book` table on first run (`ddl-auto=update`).

## API endpoints

Base path: `/api/books`

| Method | URL | Description | Success | Error |
|---|---|---|---|---|
| GET | `/api/books` | List all books | 200 OK | |
| GET | `/api/books/{id}` | Get one book | 200 OK | 404 Not Found |
| POST | `/api/books` | Create a book | 201 Created | 400 Bad Request |
| PUT | `/api/books/{id}` | Update a book | 200 OK | 400 / 404 |
| DELETE | `/api/books/{id}` | Delete a book | 204 No Content | 404 Not Found |

### Book model

| Field | Type | Rules |
|---|---|---|
| `id` | Long | Generated by the database |
| `title` | String | Required (`@NotBlank`) |
| `author` | String | Required (`@NotBlank`) |
| `isbn` | String | Optional |
| `price` | Double | Zero or more (`@PositiveOrZero`) |

### Example request

```http
POST /api/books
Content-Type: application/json

{
  "title": "235073U - Twilight",
  "author": "Stephenie Meyer",
  "isbn": "367392825788",
  "price": 4000.00
}
```

Response `201 Created`:

```json
{
  "id": 3,
  "title": "235073U - Twilight",
  "author": "Stephenie Meyer",
  "isbn": "367392825788",
  "price": 4000.0
}
```

Sending a blank `title` or `author`, or a negative `price`, returns `400 Bad Request`.
